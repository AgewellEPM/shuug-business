Gig Tax Pros — reusable app tour

Host this directory together. Open index.html to preview. The existing website build includes it at /tour/.

The H.264/AAC MP4 is the same video bundled in the iPhone app. English captions, chapter times, a poster and the full transcript are included. Playback uses native video controls and does not autoplay or contact external services.

To embed in another existing page, copy the .gig-tour element, load player.css and player.js, and retain the relative asset paths (or adjust them to your hosted directory).

No website deployment is performed by this export.
