# Platform logo sources

Downloaded November 7, 2026. These remain the respective platforms' trademarks.
The site is independent; these marks identify supported gig platforms.

- Uber: https://commons.wikimedia.org/wiki/File:Uber_logo_2018.svg
  Authentic 2018 wordmark; original source credited to Uber's newsroom. Black
  vector is displayed white using CSS on the dark platform bar.
- Lyft: https://www.lyft.com/press/media-kit
  Unchanged transparent pink PNG from the official media kit, 1600×1081.
- DoorDash: https://about.doordash.com/en-us/company
  Official symbol/wordmark vector paths combined into a standalone SVG.
- Instacart: https://docs.instacart.com/developer_platform_api/guide/concepts/design/logos/
  Official all-white wordmark from the published logo download pack.
- Amazon Flex: https://flex.amazon.com/
  Official full logo vector, with white currentColor resolved explicitly and
  the official blue retained.

SVGs were parsed and checked for script/external resource references.
