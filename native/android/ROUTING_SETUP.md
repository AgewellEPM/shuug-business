# Native road routing configuration

Google Maps is now the default native map and routing path. Directions explicitly
opens the Google Maps Android package. In-app comparisons require the native Maps
SDK setup and authenticated driver Google Routes readiness; missing configuration
never falls back to an OSRM demonstration.

The complete client/server contract, restricted-key setup, operational privacy
boundary, explicit OSRM option and verification limits are in
[Android routing setup](../../docs/ROUTING_SETUP.md).
